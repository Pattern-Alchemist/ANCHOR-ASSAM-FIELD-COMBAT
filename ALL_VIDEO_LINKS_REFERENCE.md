## Troubleshooting

### If a video doesn't play:
1. Check your internet connection
2. Try refreshing the page
3. Clear your browser cache
4. Try playing the video directly on YouTube using the link

### If you see a black screen:
1. Wait 2-3 seconds for the video to load
2. Click the play button
3. Check if ad-blockers are interfering (temporarily disable)

### Embedding Issues:
If embedded videos don't work in the app, you can access all videos directly on YouTube using the provided links.
