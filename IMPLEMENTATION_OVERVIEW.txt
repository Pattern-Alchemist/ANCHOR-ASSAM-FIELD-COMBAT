QUICK START

Add Videos to Any Component in 3 Lines:

  import { VideoManager } from './components';
  
  <VideoManager drillId="drill-id" trackId="track-id" />


Display Videos for a Drill:

  import { useDrillVideos } from './hooks/useVideo';
  
  const { videos, isEmpty } = useDrillVideos(drillId);


Play a Video:

  import { VideoPlayer } from './components';
  
  <VideoPlayer videoUrl={url} video={video} onClose={handleClose} />
